# Security Policy

## Supported Versions

Moni does not yet maintain a versioned release/support matrix. Only the latest commit on the default branch (`main`) is supported — please update to the latest commit before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| `main` (latest commit) | :white_check_mark: |
| Older commits / forks  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **Moni**, please do NOT open a public GitHub issue. Instead, report security issues directly to the maintainer:

- Email: `photoshop3rrr@users.noreply.github.com`

Please include:
1. Description of the vulnerability and its potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Deployment mode (`single_user` or `multi_tenant`).

We appreciate your effort to responsibly disclose security findings and will work to address verified vulnerabilities promptly.
